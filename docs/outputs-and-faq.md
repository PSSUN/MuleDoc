# Outputs and FAQ

## Recommended Output Organization

Use a consistent `result_folder` or `settings.output_dir` and keep per-sample outputs in separate subdirectories.

## Typical Output Structure (Example)

```text
result_or_output_dir/
├─ sampleA/
│  ├─ sampleA_barcode_snv_binary_matrix.h5ad
│  ├─ sampleA_alt_counts.txt
│  └─ ...
├─ sampleB/
│  └─ ...
├─ all_samples_merged_barcode_snv_matrix.h5ad
├─ finetune_aligned.h5ad
├─ rna_backbone_pretrained.pt
├─ snv_perturbation_model.pt
├─ top_snv_attention.csv
└─ snv_perturbation_scores_by_celltype.csv
```

## Quick File Purpose Reference

| File | Purpose |
|---|---|
| `all_samples_merged_barcode_snv_matrix.h5ad` | Core input to `snv_eff.py` |
| `finetune_aligned.h5ad` | RNA data aligned for backbone/finetune workflow |
| `rna_backbone_pretrained.pt` | Pretrained RNA backbone checkpoint |
| `snv_perturbation_model.pt` | Final SNV perturbation model checkpoint |
| `top_snv_attention.csv` | SNV ranking by attention signal |

## Frequently Asked Questions

### Q1: `bam2vcf.sh` fails because `.bai` is missing
A: Each BAM must have an index file (`sample.bam.bai` or `sample.bai`).

### Q2: `snv2barcode.py` reports `Invalid data_type`
A: `settings.data_type` must be either `sc` or `spatial`.

### Q3: AF filtering removes almost all sites
A: Check the following:
- `af_field` exists in INFO fields of annotated VCF
- `af_max` is not overly strict
- SNV naming format matches annotated VCF conventions

### Q4: Training scripts report missing config keys
A: Verify these keys in `train_config.yaml`:
- `pre_train.align.pretrain_adata`
- `pre_train.align.finetune_adata`
- `pre_train.training.num_epochs`
- `snv_eff.adata_snv`
- `snv_eff.ann_csv`

### Q5: Distributed mode does not activate
A: Launch `snv_eff.py` with `torchrun`; required distributed env vars are injected by `torchrun`.

### Q6: `snv_eff.py` cannot find `finetune_aligned.h5ad`
A: `finetune_aligned.h5ad` is generated by `pre_train.py` under `result_folder`. Ensure both stages use the same `result_folder`.

### Q7: Score outputs are empty or unexpectedly small
A: Check:
- Remaining SNV count after preprocessing/filtering
- Whether `min_cnt` / `n_top` are too strict
- Whether `top_k_attention` is too small
